# 小生意 Small Business

A static interactive student project about Taiwan street vendors and small businesses.

The site includes hand-drawn page art, booth introductions, hover-triggered stall sounds, interview videos, and a small game experience.

## Pages

- `index.html` - home page
- `booth.html` - booth introductions
- `jietou.html` - street interview videos
- `qiyuan.html` - project origin
- `aboutus.html` - team introduction
- `game0.html` - game entry

## Deployment

This project is designed to run as a static site and can be hosted directly with GitHub Pages.
